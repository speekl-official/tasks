`tree` gathers two or more siblings that share a group directory or a project alias under one dimmed line naming it (`ops/`, `api:`), each named by the path below it, as `index.md` lists a group; a prefix only one sibling shows stays on its line, and the line stands where its first task sorts. Groups are no level for `--depth`, and the JSON is the flat collection it was.
